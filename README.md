# Week 8 – Category B Java Solutions

Five independent Java console programs based on the uploaded assignment PDF.

## Programs
1. `P1_Hostel_Laundry_Queue/HostelLaundryDemo.java` — wash types, machine availability, cycle completion.
2. `P2_Assignment_Submission_Portal/AssignmentPortalDemo.java` — assignment-specific late penalties, grading status, resubmission guard.
3. `P3_Campus_Premiere_Ticket_Counter/CampusTicketDemo.java` — seat prices, booking limit, duplicate-seat prevention, cancellation.
4. `P4_FitZone_Membership_Desk/FitZoneDemo.java` — plan fees, membership status transitions, check-in.
5. `P5_Campus_Notice_Broadcaster/NoticeBoardDemo.java` — department targeting and polymorphic notification channels.

## Run
Requires JDK 11 or later. From the relevant program folder:
```bash
javac HostelLaundryDemo.java
java HostelLaundryDemo
```
Use the matching class name for each other folder.

Each program is self-contained, so compile and run them separately. Monetary values and the sample dates are based on the assignment. The submission portal uses March 2026 for its sample dates so the due-date examples remain consistent with the PDF's March 10/12 dates.
